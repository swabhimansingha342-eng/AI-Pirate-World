# AI Pirate World: The Lost Treasure

A 3D AI-powered treasure-hunting and exploration game developed using Unity 6.3.

## Project Goal

Players explore a dynamically generated pirate world,
discover clues, solve puzzles, interact with NPCs,
experience dynamic events, and discover hidden treasures.

## Technologies

- Unity 6.3 LTS
- C#
- Git
- GitHub
- VS Code
- Claude Code
- AI-generated game content
- ESP32
- Wi-Fi
- MQTT
- CNS authentication
- HMAC-SHA256
